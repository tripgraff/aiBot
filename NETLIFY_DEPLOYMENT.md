# 🚀 Развертывание через Netlify

## Пошаговая инструкция:

### Шаг 1: Перейдите на Netlify
1. Откройте браузер и перейдите на [netlify.com](https://netlify.com)
2. Нажмите **"Sign up"** или **"Log in"** (если уже есть аккаунт)

### Шаг 2: Создайте новый сайт
1. На главной странице нажмите **"Add new site"**
2. Выберите **"Deploy manually"**

### Шаг 3: Загрузите файлы
1. В области **"Want to deploy a new site without connecting to Git?"**
2. Перетащите файл `xfusion-webapp.zip` в область загрузки
3. Или нажмите **"Browse to upload"** и выберите файл

### Шаг 4: Дождитесь развертывания
- Netlify автоматически распакует архив и развернет сайт
- Процесс займет 1-2 минуты
- Вы увидите сообщение **"Site deployed successfully"**

### Шаг 5: Получите URL
- Netlify автоматически создаст URL вида: `https://random-name-123456.netlify.app`
- Этот URL будет вашим публичным адресом веб-приложения

### Шаг 6: Обновите URL в боте
1. Откройте файл `bot.py`
2. Найдите строку с `webapp_url`
3. Замените URL на ваш Netlify URL:

```python
webapp_url = "https://YOUR-NETLIFY-URL.netlify.app"
```

### Шаг 7: Протестируйте
1. Запустите бота: `python3 bot.py`
2. Нажмите "💬 Создать новый чат"
3. Нажмите "🌐 Открыть выбор моделей"
4. Веб-приложение должно открыться с логотипом!

## Дополнительные возможности Netlify:

### Переименование сайта
1. В панели управления сайтом перейдите в **"Site settings"**
2. В разделе **"Site details"** нажмите **"Change site name"**
3. Введите желаемое имя (например, `xfusion-ai`)
4. Новый URL: `https://xfusion-ai.netlify.app`

### Настройка домена (опционально)
- В **"Domain management"** можно подключить собственный домен
- Или использовать поддомен Netlify

## Готово! 🎉
Ваше веб-приложение теперь доступно по HTTPS и готово к использованию в Telegram боте.
