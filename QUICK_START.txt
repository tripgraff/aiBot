2️⃣  ID УЖЕ ДОБАВЛЕН В КОД! ✅
   • Строка 20: ADMIN_IDS = [376978188]

3️⃣  ЗАПУСТИ БОТА:
   python3 bot.py

4️⃣  ОСНОВНЫЕ АДМИН-КОМАНДЫ:

   📊 СТАТИСТИКА:
   /admin_stats    - общая статистика бота
   
   👥 ПОЛЬЗОВАТЕЛИ:
   /admin_users    - список всех пользователей  
   
   💬 ЧАТЫ (НОВОЕ!):
   /admin_chats USER_ID        - список чатов пользователя
   /admin_chat USER_ID CHAT_ID - просмотр конкретного чата
   
   Пример:
   /admin_chats 376978188
   /admin_chat 376978188 a1b2c3d4

5️⃣  КАК РАБОТАЮТ ЧАТЫ:

   • Пользователь пишет → создается новый чат с уникальным ID
   • Название генерируется из первого сообщения
   • /clear → чат завершается, показывается ID и название
   • Новое сообщение → создается новый чат

   📋 Пример завершения чата:
   
   🆔 ID: a1b2c3d4
   📝 Название: Привет! Расскажи про Python
   💬 Сообщений: 12
