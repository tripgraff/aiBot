## 🚀 Что нужно сделать СЕЙЧАС

### Шаг 1: Деплой на Netlify (5 минут)

**Самый простой способ:**
1. Откройте https://www.netlify.com/
2. Зарегистрируйтесь (можно через GitHub)
3. "Add new site" → "Deploy manually"
4. Перетащите папку `webapp/` в окно
5. Скопируйте URL (например: `https://abc123.netlify.app`)

**Подробнее:** `webapp/QUICKSTART.md`

### Шаг 2: Обновите bot.py

Замените URL в 3 местах:
```bash
# Найдите:
grep -n "your-netlify-app" bot.py

# Замените (вручную или через команду):
# Строки: 2347, 2736, 2893
```

**Было:**
```python
webapp_url = "https://your-netlify-app.netlify.app"
```

**Стало:**
```python
webapp_url = "https://ВАШ-URL.netlify.app"  # Ваш URL с Netlify
```

### Шаг 3: Перезапустите бота

```bash
pkill -9 -f "bot.py"
python3 bot.py
```

### Шаг 4: Протестируйте

1. Откройте бота
2. `/start`
3. "💬 Создать новый чат" → должно открыться веб-приложение
4. Выберите модель → чат создается
5. Проверьте все функции (см. ниже)

### Автоматическая замена URL:
```bash
# Mac/Linux:
sed -i '' 's|https://your-netlify-app.netlify.app|https://ВАШ-URL.netlify.app|g' bot.py

# Linux (без Mac):
sed -i 's|https://your-netlify-app.netlify.app|https://ВАШ-URL.netlify.app|g' bot.py
```

## 🎨 Дополнительные настройки (опционально)

3. Новый URL: `https://xfusion-ai-models.netlify.app`
4. Обновите URL в `bot.py`

### Добавить новую модель:
1. Откройте `bot.py` → добавьте модель в `MODELS`
2. Откройте `webapp/index.html` → добавьте модель в `models`
3. Задеплойте обновленную версию на Netlify
4. Перезапустите бота

### Изменить цвета:
1. Откройте `webapp/index.html`
2. Найдите CSS переменные `--tg-theme-*`
3. Измените или добавьте свои цвета
4. Задеплойте обновление

## 🐛 Проблемы?

### Веб-приложение не открывается:
- Проверьте URL в браузере (должна открываться страница)
- URL должен начинаться с `https://`
- Убедитесь, что URL в `bot.py` правильный

### Модель не выбирается:
- Откройте веб-приложение в браузере → F12 → Console
- Проверьте логи бота (должно быть "выбрал модель через веб-приложение")
- Убедитесь, что `web_app_data` обрабатывается

### Бот не запускается:
- Проверьте API ключи в `.env`
- Проверьте зависимости: `pip3 install -r requirements.txt`
- Посмотрите логи ошибок
