# ⚡ Быстрый старт - Веб-приложение xFusion AI

## 🎯 Что нужно сделать (5 минут)

### 1️⃣ Деплой на Netlify

**Вариант A: Drag & Drop (самый быстрый)**
1. Откройте https://www.netlify.com/ → Sign up (через GitHub)
2. После входа: "Add new site" → "Deploy manually"
3. Перетащите папку `webapp/` в окно браузера
4. Дождитесь деплоя (30-60 секунд)
5. **Скопируйте URL** (например: `https://brilliant-choux-123456.netlify.app`)

**Вариант B: GitHub (для обновлений)**
1. Создайте репозиторий на GitHub
2. Загрузите папку `webapp/` в репозиторий
3. На Netlify: "Add new site" → "Import an existing project"
4. Выберите GitHub → ваш репозиторий
5. Publish directory: `webapp`
6. Deploy site → **скопируйте URL**

### 2️⃣ Обновите bot.py

Найдите и замените (3 места):
```python
# Было:
webapp_url = "https://your-netlify-app.netlify.app"

# Стало (ваш URL):
webapp_url = "https://brilliant-choux-123456.netlify.app"
```

**Автоматическая замена:**
```bash
# Mac/Linux:
sed -i '' 's|https://your-netlify-app.netlify.app|https://ВАШ-URL.netlify.app|g' bot.py

# Или вручную через поиск (Cmd+F / Ctrl+F)
```

### 3️⃣ Перезапустите бота

```bash
pkill -9 -f "bot.py"
python3 bot.py
```

### 4️⃣ Тестирование

1. Откройте бота в Telegram
2. Нажмите "💬 Создать новый чат"
3. Должно открыться веб-приложение
4. Выберите модель → чат создается автоматически ✅

## 🎨 Настройка имени (опционально)

На Netlify:
1. Site settings → "Change site name"
2. Введите: `xfusion-ai-models` (или другое имя)
3. Новый URL: `https://xfusion-ai-models.netlify.app`
4. Обновите `bot.py` с новым URL

## 🐛 Возможные проблемы

### ❌ Приложение не открывается
**Решение:**
- Проверьте URL: должен начинаться с `https://`
- Откройте URL в браузере → должна быть страница
- Убедитесь, что URL в `bot.py` совпадает с Netlify

### ❌ Модель не выбирается
**Решение:**
1. Откройте приложение в браузере
2. F12 → Console → смотрите ошибки
3. Выберите модель → нажмите "Выбрать модель"
4. Проверьте логи бота (должно быть "выбрал модель через веб-приложение")

### ❌ Бот говорит "Выберите модель", но я выбрал
**Решение:**
- Проверьте, что бот обрабатывает `web_app_data`
- В логах должно быть: "Пользователь {id} выбрал модель {model_id} через веб-приложение"
- Если нет → проблема в передаче данных (проверьте консоль браузера)
