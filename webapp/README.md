# 🤖 xFusion AI - Веб-приложение для выбора моделей

## 📋 Описание
Telegram Web App для удобного выбора AI-моделей в боте xFusion AI.

## ✨ Возможности
- 🔍 **Поиск моделей** по названию и описанию
- 🏷️ **Фильтр по создателям**: OpenAI, Anthropic, Google, Groq, Yandex
- 🎨 **Адаптивный дизайн** под тему Telegram
- 📱 **Оптимизировано для мобильных устройств**
- ⚡ **Быстрая загрузка** и отзывчивый интерфейс

## 📦 Структура
```
webapp/
├── index.html              # Основной файл приложения
├── README.md              # Эта инструкция
└── NETLIFY_DEPLOY.md      # Инструкция по деплою
```

## 🚀 Быстрый старт

### 1. Деплой на Netlify
Следуйте инструкциям в [NETLIFY_DEPLOY.md](./NETLIFY_DEPLOY.md)

### 2. Настройка бота
В файле `bot.py` замените:
```python
webapp_url = "https://your-netlify-app.netlify.app"
```
на ваш URL с Netlify.

### 3. Запуск
```bash
python3 bot.py
```

## 🎯 Как это работает

1. **Пользователь нажимает "💬 Создать новый чат"**
   - Если модель уже выбрана → чат создается автоматически
   - Если модель не выбрана → открывается веб-приложение

2. **В веб-приложении**
   - Пользователь видит все доступные модели
   - Может искать или фильтровать по создателю
   - Выбирает модель → нажимает "Выбрать модель"

3. **Бот получает данные**
   - Через `web_app_data` приходит выбранная модель
   - Автоматически создается чат с этой моделью
   - Модель сохраняется для будущих чатов

## 🔄 Обновление моделей

Чтобы добавить/изменить модели:

1. Откройте `webapp/index.html`
2. Найдите объект `models`:
```javascript
const models = {
    'model-id': {
        name: 'Название модели',
        emoji: '🤖',
        description: 'Описание модели',
        category: 'openai' // openai, anthropic, google, groq, yandex
    },
    // ...
};
```
3. Добавьте новую модель или измените существующую
4. Обновите также `bot.py` в объекте `MODELS`
5. Задеплойте обновленную версию

## 📝 Технические детали

- **Framework**: Vanilla JavaScript (без зависимостей)
- **Telegram SDK**: https://telegram.org/js/telegram-web-app.js
- **Стилизация**: CSS с переменными темы Telegram
- **Передача данных**: JSON через `tg.sendData()`

## 🐛 Отладка

### Проблема: данные не передаются
**Решение**: 
- Проверьте консоль: `F12` → Console
- Убедитесь, что `tg.sendData()` вызывается
- Проверьте формат JSON: `{ model_id: "..." }`

### Проблема: неправильные цвета
**Решение**:
- Telegram автоматически применяет тему
- Проверьте переменные `--tg-theme-*` в CSS
- Протестируйте в светлой и темной теме
