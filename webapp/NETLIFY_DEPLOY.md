# 🚀 Деплой веб-приложения на Netlify

## Шаг 1: Подготовка
1. Убедитесь, что файл `index.html` находится в папке `webapp/`

## Шаг 2: Регистрация на Netlify
1. Перейдите на https://www.netlify.com/
2. Нажмите "Sign up" (можно через GitHub)
3. Войдите в свой аккаунт

## Шаг 3: Деплой
### Вариант А: Через интерфейс (Drag & Drop)
1. В Netlify Dashboard нажмите "Add new site" → "Deploy manually"
2. Перетащите папку `webapp/` в окно браузера
3. Дождитесь завершения деплоя
4. Скопируйте URL (например: `https://your-app-name.netlify.app`)

### Вариант Б: Через GitHub (рекомендуется)
1. Создайте репозиторий на GitHub
2. Загрузите папку `webapp/` в репозиторий
3. В Netlify Dashboard нажмите "Add new site" → "Import an existing project"
4. Выберите GitHub и свой репозиторий
5. Настройки:
   - **Build command**: оставьте пустым
   - **Publish directory**: `webapp`
6. Нажмите "Deploy site"
7. Скопируйте URL

## Шаг 4: Настройка бота
1. Откройте `bot.py`
2. Найдите все строки с `webapp_url = "https://your-netlify-app.netlify.app"`
3. Замените на свой URL с Netlify
4. Сохраните файл

Пример:
```python
webapp_url = "https://xfusion-ai-models.netlify.app"  # Ваш URL
```

## Шаг 5: Запуск бота
1. Перезапустите бота
2. Проверьте работу веб-приложения

## 🎨 Настройка (опционально)
### Изменить имя сайта:
1. В Netlify Dashboard → Site settings
2. "Change site name"
3. Введите новое имя (например: `xfusion-ai-models`)
4. Обновите URL в `bot.py`

### Обновление приложения:
- **Drag & Drop**: просто перетащите папку снова
- **GitHub**: сделайте commit и push - Netlify обновится автоматически

## ✅ Проверка работы
1. Откройте URL в браузере
2. Должна открыться страница с выбором моделей
3. В боте нажмите "🤖 Модели" → должно открыться приложение

## 🔧 Возможные проблемы

### Приложение не открывается в Telegram:
- Убедитесь, что URL начинается с `https://`
- Проверьте, что сайт успешно задеплоен на Netlify
- URL должен быть публично доступен

### Данные не передаются боту:
- Откройте консоль браузера (F12) → проверьте ошибки
- Убедитесь, что в коде используется `tg.sendData()`
- Проверьте, что бот обрабатывает `web_app_data`

### Неправильная тема:
- Telegram Web App автоматически применяет тему пользователя
- Если нужно, можно настроить цвета в CSS
